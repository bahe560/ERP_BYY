## طريقة إضافة قرار

أضف سجلًا جديدًا يتضمن:
- معرفًا فريدًا.
- الموضوع.
- الحالة: مقترح / معتمد / مرفوض / مؤجل / ملغى.
- نص القرار أو المقترح.
- المصدر والمبررات.
- تاريخ الاعتماد والجهة المعتمدة عند توفرهما.
- أثر القرار والوثائق المتأثرة.
