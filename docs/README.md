## قاعدة إدارة الوثائق

1. لا يُعد أي اقتراح قرارًا معتمدًا إلا بعد موافقة صريحة.
2. تُحفظ نسخ العمل مع أرقام إصدارات واضحة، ويُذكر وضع اعتماد كل نسخة.
3. لا تُدمج تغييرات هذا الفرع في `main` إلا بعد المراجعة والموافقة.
4. لا تُعامل أدلة ONYX الخارجية على أنها مصادر رسمية ما لم يثبت ذلك.
