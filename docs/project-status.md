# الحالة الحالية للمشروع

## نقطة الاستمرار المعتمدة

- الإصدار المعتمد كنقطة استمرار رسمية: **v0.7**.
- سجل الوظائف في نقطة v0.7: 32 وظيفة.
- سجل الشاشات التفصيلي: 11 سجلًا بمعرفات ثابتة من عائلة `ONX-SCR-*`.
- يجب الحفاظ على معرفات الوظائف والشاشات وعدم حذفها أو إعادة استخدامها.

## نسخ العمل اللاحقة

- v0.8: نسخة عمل لاحقة، غير معتمدة كنقطة استمرار رسمية.
- v0.9: نسخة عمل تحليلية تضمنت فحص دليل العملاء ودليل المخازن وربطًا أوليًا للأدلة بالوظائف.
- v0.9 **غير معتمدة** كنقطة استمرار رسمية حتى الآن.

## وضع المراجعة

أُعد سجل وظائف Excel v0.9 للمراجعة، ويتضمن 16 ورقة عمل، و32 سجل وظيفة، و11 سجل شاشة، وورقتي تحقق وربط للأدلة. طلب المستخدم مراجعة سجل Excel قبل الانتقال إلى التحليل التفصيلي.

المطلوب قبل اعتماد v0.9:
1. مراجعة حالات الإثبات بحيث تميز بين إثبات وجود الموضوع وإثبات تفاصيل تنفيذه.
2. فصل رقم صفحة PDF الفعلية عن رقم الصفحة المطبوعة في الدليل.
3. تقييد وصف مصادر الأدلة بما يثبته مسار الحصول عليها وبياناتها.
4. مراجعة ربط الأدلة بالوظائف، بما في ذلك القيود المعروفة على بعض الوظائف.

## قيود العمل الحالية

- لا يبدأ التحليل التفصيلي للشاشات الـ11 قبل استلام مراجعة Excel أو توجيه صريح محدد بالبدء.
- لا يُعلن اكتمال تحليل ONYX بمجرد مراجعة الشاشات الـ11؛ لا تزال أدلة وحدات أخرى مطلوبة.
- لا يبدأ تصميم قاعدة البيانات أو SQL أو البرمجة أو اختيار التقنيات قبل اكتمال التحليل الوظيفي والمعماري واعتماد خطة التنفيذ.
- لا تُعدّل ملفات أو مستودعات أو قواعد بيانات مشاريع سابقة.

## الخطوة التالية

استلام ملاحظات مراجعة سجل Excel v0.9، ثم تحديث حالات الإثبات ومراجع الصفحات والربط، وإعادة إصدار نسخة للمراجعة قبل أي اعتماد رسمي.
